# 阶段验收标准

更新时间：2026-05-13

## 验收项

- AC-301：任务运行时可完成最小闭环
  验收方式：`test`
  通过标准：创建任务后可触发 mock 执行，状态至少覆盖 `CREATED`、`RUNNING`、`SUCCEEDED` 与失败分支

- AC-302：任务 SSE 事件流可用
  验收方式：`manual`
  通过标准：客户端订阅 `SSE` 后，能够收到任务状态变化、日志片段、摘要完成等事件

- AC-303：聊天 SSE 事件流可用
  验收方式：`manual`
  通过标准：客户端订阅聊天流后，发送一条用户消息可收到 AI 增量输出与完成事件

- AC-304：AI 聊天网络请求使用 `OkHttp`
  验收方式：`manual`
  通过标准：AI 客户端实现位于后端代码中，底层 HTTP 客户端为 `OkHttp`

- AC-305：工具辅助使用 `Hutool`
  验收方式：`manual`
  通过标准：字符串、集合、ID、时间等公共辅助代码优先使用 `Hutool` 提供的能力
