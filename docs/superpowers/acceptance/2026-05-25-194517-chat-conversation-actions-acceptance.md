# 会话菜单与消息操作验收标准

1. 点击会话列表三点按钮后，菜单中可见：
   - 重命名对话
   - 置顶对话或取消置顶
   - 分享对话
   - 批量管理
   - 导出对话
   - 删除对话
2. 会话菜单中不出现“移动到分组”。
3. 点击“置顶对话”后，该会话在所属分组内移动到顶部；刷新后顺序仍保留。
4. 已置顶会话再次打开菜单时，操作文案变为“取消置顶”。
5. 点击“分享对话”后，会调用分享链路并复制链接，不使用原生弹窗。
6. 点击“导出对话”后，可继续选择 `Markdown` 或 `JSON`。
7. 选择导出格式后，会触发浏览器下载。
8. 点击“批量管理”后，侧栏进入批量模式，会话可被勾选。
9. 批量模式中支持全选、取消、批量导出、批量删除。
10. 批量删除前出现自定义确认弹窗。
11. 消息底部展示分享按钮。
12. 消息底部展示重新生成按钮。
13. 非最后一条助手消息的重新生成按钮保持禁用。
14. 亮色与暗色模式下菜单、工具条、弹窗、滚动容器均可读可用。
