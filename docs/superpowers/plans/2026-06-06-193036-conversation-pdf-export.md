# Conversation PDF Export Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. It will decide whether each batch should run in parallel or serial subagent mode and will pass only task-local context to each subagent. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复用户端会话导出 PDF 后浏览器无法加载的问题。

**Architecture:** 保持导出入口和菜单交互不变，仅调整 `useChatWorkspace` 的导出序列化层。PDF 分支从纯文本伪装 MIME 改为生成合法 PDF；真实浏览器优先使用 Canvas 图片页保证中文可读，测试或无 Canvas 环境回退到结构化文本 PDF，其他格式沿用现有文本/HTML/JSON 序列化路径。

**Tech Stack:** React Hook、TypeScript、Vitest、JSDOM Blob API。

Ensure JSON/TXT/Word/Markdown still return their existing content and MIME types, while PDF returns generated bytes with MIME `application/pdf`.
