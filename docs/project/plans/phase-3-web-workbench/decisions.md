# 阶段决策记录

更新时间：2026-05-13

## 决策 001

- 标题：实时推送统一使用 `SSE`
- 日期：2026-05-13
- 背景：当前工作台需求主要是单向推送任务事件与 AI 输出，不需要双向长连接协议
- 结论：任务事件流与 AI 聊天流均采用 `SSE` 实现，不引入 `WebSocket`
- 影响范围：后端事件推送实现、前端订阅方式、任务/聊天接口设计

## 决策 002

- 标题：AI 流式输出复用聊天事件通道
- 日期：2026-05-13
- 背景：工作台后续会同时展示任务时间线与 AI 回复，若拆成多种临时接口会增加前端接入复杂度
- 结论：聊天模块以会话为单位提供 SSE 通道，用户发消息后通过该通道接收增量 token、完成、失败事件
- 影响范围：聊天模块接口、消息落库时机、AI 客户端实现

## 决策 003

- 标题：未登录可浏览，仅在发送 AI 请求时触发登录
- 日期：2026-05-14
- 背景：工作台需要支持未登录用户先浏览界面与控制台，避免首次进入即被全屏遮罩阻断
- 结论：取消全页未登录拦截；仅在聊天发送等 AI 请求入口执行登录校验，未登录时弹出登录表单
- 影响范围：前端聊天交互流程、认证弹窗触发时机、登录状态判断逻辑
