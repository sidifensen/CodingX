# Phase 1：Web 页面骨架

更新时间：2026-05-12

## 一、概述

这一期只做 Web 的第一层外壳，目标是先把产品长什么样、入口怎么走、页面怎么组织定下来。

这一期不追求任务真正跑通，重点是先把用户能看到的主界面搭起来，让后续任务主干和工作台有稳定承载面。

## 二、目标

- 确定 Web 版产品信息架构
- 建立前端基础工程
- 建立导航结构和主页面路由
- 为 Skill 和 MCP 预留稳定入口
- 为后续 Electron 复用前端做准备

## 三、要做的事情

- 初始化 `React + Vite+` 前端工程
- 接入 `Tailwind CSS`
- 做首页任务入口
- 做左侧导航
- 做编码模式主界面
- 做任务列表页骨架
- 做任务工作台页骨架
- 在导航中预留 `Skill` 和 `MCP` 入口
- 统一基础布局、颜色变量、间距规则
