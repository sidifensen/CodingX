# 管理端 Ant Design 页面体系改造计划

## 目标

将管理端除工作台外的页面统一迁移到 Ant Design 组件体系，重点解决表格样式不统一、操作按钮缺少图标、树状/分栏控件自绘过多、弹窗和表单复用不足的问题。

## 执行步骤

1. 建立 `AdminDataTable` 和 `AdminTableActions`，统一表格留白、无竖线、分页摘要与操作按钮图标。
2. 改造反馈、MCP、用户、会话、专家、工作空间、Trace、系统配置、关键词映射等页面的表格和工具栏。
3. 改造意图树和工具意图树，使用 Ant Design Tree、Button、Tag、Modal、Form 等组件承载层级与操作。
4. 改造技能管理的列表、卡片、资源预览、编辑、上传和删除确认交互。
5. 清理旧的 `Pagination`、`DataTableCard` 遗留组件，避免新旧表格体系并存。
6. 执行单页测试、完整测试、构建和浏览器验证，并补充功能文档。

## 验收点

- 除工作台外，管理端页面不再直接使用自绘表格和旧分页组件。
- 表格整体有统一内间距，不显示竖线。
- 表格右侧操作栏按钮和页面右上角动作按钮均带 Ant Design 图标。
- 意图树使用 Ant Design Tree，分栏/详情操作使用 Ant Design Button、Tag、Modal、Form。
- MCP/工具管理相关面板使用 Ant Design 控件。
- 暗色模式下表格、弹窗、下拉、上传和树节点可读。
