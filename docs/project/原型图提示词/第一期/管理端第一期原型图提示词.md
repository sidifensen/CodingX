# 管理端第一期原型提示词（重点前置版，可直接投喂 AI）

请为“CodingX 管理端第一期”生成一套高保真 Web 端原型（桌面优先，1440x1024，中文界面，浅色主题，专业平台风格，蓝色主色，卡片化布局）。

## 重点要求（必须优先满足）
1. 所有页面必须使用中文（页面标题、菜单文案、按钮文案、表单提示、状态提示、错误提示全部为中文）
2. 页面需可点击跳转，输出完整页面流和跳转关系
3. 第一期开工范围只聚焦 Web 管理端的基础治理能力，不要出现复杂审批流和高级权限矩阵
4. 管理端风格偏专业控制台，信息密度高，但层级清楚
5. 核心操作优先放在列表页和详情页，减少空页面

## 页面与跳转关系
1）工作台首页
- 顶部核心指标卡片：用户数、任务数、运行中任务、失败任务
- 顶部右侧入口：通知中心、管理员个人中心
- 中部快捷入口：
  - 用户管理
  - 任务管理
  - 技能管理
  - MCP 管理
  - 系统配置
- 点击指标卡片 -> 对应列表页

2）用户管理页
- 搜索栏：用户名、手机号、邮箱
- 状态筛选：全部/正常/禁用/待审核
- 用户列表卡片（用户名、角色、状态、最近登录、创建时间）
- 操作：
  - 查看详情
  - 禁用/启用
  - 重置密码

3）用户详情页
- 展示用户基础信息、状态、最近行为、关联任务
- 操作：
  - 编辑信息
  - 调整角色
  - 禁用/启用

4）任务管理页
- 搜索栏：任务标题、任务 ID、状态
- 状态筛选：全部/待执行/进行中/已完成/失败
- 任务列表（标题、目标摘要、状态、执行目标、更新时间）
- 点击任务 -> 任务详情

5）任务详情页
- 展示任务基础信息、执行记录、事件流、结果摘要
- 右侧辅助区：审计信息、创建人、最近更新

6）技能管理页
- 技能列表（名称、分类、状态、启用范围）
- 操作：
  - 新建技能
  - 编辑技能
  - 启用/停用
  - 查看详情

7）MCP 管理页
- MCP 列表（名称、状态、作用范围、最近连接时间）
- 操作：
  - 新建 MCP
  - 编辑 MCP
  - 启用/停用
  - 查看详情

8）系统配置页
- 基础系统参数
- 前端入口配置
- 默认任务策略
- 通知策略
- 保存按钮固定在底部

9）通知中心
- 分类筛选：全部/系统通知/任务通知/审批通知
- 列表卡片（标题、时间、内容、未读标识）
- 支持标记已读、全部已读

## 输出格式要求
- 输出：页面清单 + 页面跳转说明 + 关键交互标注
- 输出一套可点击原型（Prototype）
