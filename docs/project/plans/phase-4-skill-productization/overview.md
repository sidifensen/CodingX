# Phase 4：Skill 产品化

更新时间：2026-05-12

## 一、概述

这一期先做 Skill，而不是把 Skill 和 MCP 混成一个大期。

这样拆的好处是 Skill 可以先稳定成为产品能力模块，后面 MCP 再按同样的产品结构接入。

## 二、目标

- 让 Skill 成为正式模块
- 让 Skill 进入导航和页面
- 让任务能绑定 Skill
- 让工作台能看到当前任务的 Skill

## 三、要做的事情

- 做 Skill 列表页
- 做 Skill 详情页
- 做 Skill 分类
- 定义 Skill 元数据模型
- 创建任务时支持选择 Skill
- 任务详情展示已绑定 Skill
- 工作台展示当前 Skill
- 收口 Skill 模块导航和页面结构
