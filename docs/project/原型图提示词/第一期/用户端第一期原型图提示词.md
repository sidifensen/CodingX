# 用户端第一期原型提示词

请为“CodingX 用户端第一期”生成一套高保真桌面端 Web 原型（1440x1024，中文界面）。

## 重点要求（必须优先满足）
1. 所有页面必须使用中文（页面标题、菜单文案、按钮文案、表单提示、状态提示、错误提示全部为中文）
2. 左侧导航栏必须全中文，禁止出现英文菜单词
3. 页面结构必须接近“左侧导航栏 + 中央工作区 + 底部输入框”的桌面工作台形态
4. 所有页面必须复用同一套全局壳层：相同顶部栏、相同左侧导航栏、相同左下角个人信息区，不允许每个页面单独换一套头部和侧边栏
5. 全局顶部栏右上角保持留空，不生成预览、导出、分享、更多、通知、设置、帮助等额外按钮或图标
6. 页面需可点击跳转，输出完整页面流和跳转关系
7. 页面数量固定为 4 个主页面：主工作台 / 技能页 / 专家中心页 / 自动化页

## 页面与跳转关系
1）主工作台（默认页）
- 顶部细菜单栏：
  - 品牌区
  - 所有页面都复用这一套顶部栏
  - 顶部栏样式、位置、结构保持一致
  - 顶部栏右侧留空，不放任何额外操作按钮或状态图标
- 左侧固定侧边栏：
  - 左侧所有菜单、分组标题都必须使用中文
  - 顶部菜单入口：新建任务 / 技能 / 专家 / 自动化
  - 左侧菜单下方直接展示任务列表内容
  - 底部默认只显示个人信息区：个人头像 + 用户名
  - 默认不要展开账户菜单内容
  - 左侧不需要搜索框
- 右侧主内容区：
  - 支持两种状态：
    - 空白起始态（点击“新建任务”后出现）：
      - 中央欢迎区（如第二张图）
      - 下方快捷能力卡片（网页读取 / 调研分析 / 数据挖掘 / 文件管理）
      - 底部固定输入框
    - 任务详情态（点击左侧任务项后出现）：
      - 顶部任务标题与时间
      - 中间对话与结构化内容区域
      - 底部固定输入框
- 页面内部右上角保持简洁，仅在当前页面明确需要时出现内容
- 主工作台输出 1 个页面，默认展示任务详情态
- 空白起始态和账户菜单展开态作为主工作台内状态表达
- 点击顶部“新建任务”后切换到空白起始态
- 点击侧边栏任务项后切换到任务详情态
- 左下角个人信息区默认收起，点击后展开账户菜单卡片
  - 账户菜单卡片内容包括：
  - 账号头像与昵称
  - 设置
  - 深色主题开关
  - 帮助与反馈
  - 检查更新
  - 退出登录

2）技能页
- 必须复用与主工作台完全一致的顶部栏、左侧导航栏、左下角个人信息区
- 右侧内容头部：
  - 标题：技能
  - 副标题：赋予 CodingX 更强大的能力
  - 右上角：搜索技能输入框 + 添加技能按钮
- 已安装区：
  - 标题：已安装（带数量）
  - 已安装技能卡片横向布局
  - 卡片字段：技能图标、技能名称、标签（如套件）、简介
  - 已安装技能示例（至少展示 5 个）：
    - agent-browser（套件）
    - playwright-cli（套件）
    - find-skills（套件）
    - document-skills（套件）
    - finance-data（套件）
- 技能市场区：
  - 顶部标签页：推荐 / SkillHub / 套件
  - 分类筛选标签：全部、生活服务、开发工具、内容创作、数据分析、效率工具、办公协同、商业运营、知识学习等
  - 技能卡片网格（多列）：
    - 卡片字段：图标、技能名称、简介
    - 支持查看详情与安装入口
  - 推荐市场技能示例（多行网格，信息密集）：
    - 腾讯文档、腾讯会议、企业微信套件、腾讯云知（乐享）
    - 腾讯 ima、NeoData 金融搜索服务、cnb.cool、AIHOT
    - 品牌设计风格专家、fbs-bookwriter、TAPD、腾讯乐享
    - 腾讯新闻、创业可以学、腾讯云 COS、腾讯云 COS 向量
    - 腾讯技术人类智能助手、腾讯电子签、公益文书助手、公益财会助手
- 页面要有明显“已安装能力 + 可选能力市场”的双层结构

3）专家中心页
- 必须复用与主工作台完全一致的顶部栏、左侧导航栏、左下角个人信息区
- 右侧内容头部：
  - 标题：专家中心
  - 副标题：按行业分类浏览角色型专家，为任务分配合适角色
  - 右上角搜索框：搜索专家职称或描述
- 专家团模块：
  - 一级标题：专家团（带 Beta 标识）
  - 这里的“专家团”本质上是角色组合或角色团队，不是真人组织
  - 行业分类标签：全部 / OPC-一人公司 / 产品设计 / 技术工程 / 金融投资 / 数据智能 / 营销增长 / 内容创作 / 销售商务 / 运营人力 / 项目质量 / 法务安全 / 行业顾问
  - 专家团卡片网格（多列）：
    - 卡片字段：角色团队名称、角色标签、团队简介、角色头像组、使用量
    - 操作按钮：使用 / 进入
  - 支持“显示更多”入口
- 专家模块：
  - 一级标题：专家
  - 这里的“专家”本质上是单个角色卡，不是真人专家介绍页
  - 分类标签：全部 / OPC-一人公司 / 产品设计 / 技术工程 / 金融投资 / 数据智能 / 营销增长 / 内容创作 / 销售商务 / 运营人力 / 项目质量 / 法务安全 / 行业顾问
  - 排序：最热 / 最新
  - 专家卡片网格：
    - 卡片字段：角色头像、角色名称、能力标签、角色简介、使用量
    - 角色名称示例：高级开发工程师 / 内容创作专家 / 数据分析报告师 / UI 设计师 / 微信小程序开发者 / 资讯速递专家 / 前端开发工程师 / 小红书运营专家
    - 点击后进入角色详情或角色介绍面板
- 与侧边栏联动：
  - 点击左侧“专家”菜单 -> 进入专家中心页
  - 点击专家或专家团卡片 -> 进入角色详情页或角色介绍面板

4）自动化页
- 必须复用与主工作台完全一致的顶部栏、左侧导航栏、左下角个人信息区
- 右侧内容头部：
  - 标题：自动化
  - 副标题：配置和管理自动化任务，按计划执行工作流
  - 右上角按钮：手动新建 / 在对话中创建
- 标签页：
  - 已配置
  - 执行历史
  - 任务模板（默认激活）
- 任务模板区（卡片网格，多列）：
  - 每张卡片字段：图标、模板名称、模板简介
  - 示例模板包括：
    - 每日 AI 新闻简报
    - 品牌舆情监控周报
    - 每周竞品动态追踪
    - 股价监控与预警
    - 安全漏洞扫描
    - 扫描提交发现 Bug
    - 补充测试覆盖
    - 每日变更摘要
- 与侧边栏联动：
  - 点击左侧“自动化”菜单 -> 进入自动化页
  - 点击模板卡片 -> 打开该模板的创建流程（可弹层或右侧面板）

## 视觉与交互提示
- 左侧导航要固定，保持窄边栏风格
- 主内容区要有明显的卡片分层和留白
- 文本内容建议采用“文档 / 目录树 / 代码块”混排方式
- 底部输入框固定吸附，带附件、麦克风、发送等轻量图标

## 内容示例
- 右侧工作区可以展示类似下面的内容块：
  - 代码目录树
  - Frontend（React 前端）
  - Backend（Spring Boot 后端）
  - Docs（文档说明）
  - 任务计划或结构化文档
