# Phase 5：MCP 产品化

更新时间：2026-05-12

## 一、概述

这一期再做 MCP。这样可以让 MCP 的产品设计建立在 Skill 已经成型的基础上，而不是两块同时发散。

重点是把 MCP 做成正式模块，并进入任务配置和工作台展示。

## 二、目标

- 让 MCP 成为正式模块
- 让任务能绑定 MCP
- 让工作台能看到当前任务的 MCP
- 为后续 Electron 本地 MCP 桥接做准备

## 三、要做的事情

- 做 MCP 列表页
- 做 MCP 详情页
- 定义 MCP 配置模型
- 增加 MCP 状态字段
- 展示 MCP 作用范围
- 创建任务时支持选择 MCP
- 任务详情展示已绑定 MCP
- 工作台展示当前 MCP
