# 专家中心验收标准

1. 用户端专家页从真实接口加载专家列表，至少展示名称、分类、描述、标签和示例问题。
2. 用户在专家页选择专家后，会切回聊天页，并将输入框内容替换为该专家的 `presetQuestion`。
3. 聊天输入区在“技能”按钮旁新增“专家”按钮，能打开专家列表并切换当前专家。
4. 发送消息时，SSE 请求地址包含 `expertCode`，后端能在聊天 system prompt 中注入该专家的提示词。
5. 同一会话中切换专家后，下一条消息按新专家生效，不要求新建会话。
6. 聊天工作区回放接口可返回最新运行绑定的当前专家信息。
7. 管理端新增专家管理页，使用表格组件展示分页数据，支持新增、编辑、删除。
8. 数据库提供 `expert`、`task_expert` 结构、中文注释、索引和迁移脚本。
9. 初始化后至少存在 20 条启用状态的中文专家数据。
10. 前后端相关测试覆盖：
   - 后端控制器/服务专家接口
   - 聊天 expert 透传与提示词注入
   - 用户端 `buildStreamRequestUrl`
   - 聊天页专家选择交互
   - 管理端专家页 CRUD
