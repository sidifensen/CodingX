# Phase 6：Electron 宿主与本地资源

更新时间：2026-05-12

## 一、概述

这一期先做 Electron 的宿主能力，不急着先接真实本地执行。

重点是先把现在的 Web 前端搬进 Electron，并让桌面端开始具备本地仓库和本地文件入口。

## 二、目标

- 让同一套前端运行在 Electron 中
- 增加宿主识别与 capability 基础层
- 支持本地仓库选择
- 支持本地文件能力入口

## 三、要做的事情

- 搭 Electron 主进程
- 搭 Electron 窗口壳
- 让 Web 前端在 Electron 中运行
- 增加宿主识别与 capability 基础层
- 做本地目录选择器
- 做本地仓库路径绑定
- 做文件访问权限确认
- 暴露本地资源能力接口
