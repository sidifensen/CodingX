# Phase 2：Web 任务主干

更新时间：2026-05-12

## 一、概述

这一期开始把 Web 从静态产品壳推进成真正可交互的任务产品。

重点是先把任务最小模型和最小 API 做通，让用户能真正创建任务、查看任务、进入任务详情。

## 二、目标

- 定义任务主干模型
- 建立最小任务 API
- 打通任务创建与任务查询
- 让 Web 页面不再只是静态骨架

## 三、要做的事情

- 定义 `task` 最小模型
- 定义 `workspace` 最小模型
- 定义 `event` 最小模型
- 定义 `artifact` 最小模型
- 实现 `POST /tasks`
- 实现 `GET /tasks`
- 实现 `GET /tasks/{taskId}`
- 接通前端任务创建表单
- 接通前端任务列表页
- 接通前端任务详情页
