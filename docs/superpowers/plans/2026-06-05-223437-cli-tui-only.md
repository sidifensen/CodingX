# CLI TUI Only Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. It will decide whether each batch should run in parallel or serial subagent mode and will pass only task-local context to each subagent. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 CodingX CLI 从文本 `exec` 任务入口切换为默认 TUI 终端入口。

**Architecture:** 保留 `login` 作为配置命令，但删除 `codingx exec "任务"` 非交互任务形态。`codingx` 和 `codingx tui` 都启动 tui4j Bubble Tea 风格界面，用户任务只在 TUI 输入框中提交；TUI 通过现有 `AgentEventSource` 和 `TerminalRenderer` 消费 mock 事件流，后续真实后端只替换事件源。

**Tech Stack:** JDK 21、Maven、tui4j Bubble Tea compat、Viewport、Textarea、JUnit 5。

---

## File Structure

- Modify `cli/src/main/java/com/codingx/cli/CodingXCli.java`: 组装 TUI launcher，默认进入 TUI。
- Modify `cli/src/main/java/com/codingx/cli/command/CliCommandRunner.java`: 删除 `exec` 运行路径，新增 TUI 启动分发。
- Create `cli/src/main/java/com/codingx/cli/tui/TuiLauncher.java`: TUI 启动边界，便于命令层测试。
- Create `cli/src/main/java/com/codingx/cli/tui/CodingXTuiLauncher.java`: 使用 tui4j `Program` 启动全屏界面。
- Create `cli/src/main/java/com/codingx/cli/tui/CodingXTuiModel.java`: Bubble Tea 模型，维护 viewport、textarea、事件流和状态栏。
- Modify `cli/src/test/java/com/codingx/cli/command/CliCommandRunnerTest.java`: 验证默认入口和 `tui` 入口启动 TUI，`exec` 被拒绝。
- Create `cli/src/test/java/com/codingx/cli/tui/CodingXTuiModelTest.java`: 验证 TUI 初始视图和任务提交后的事件展示。
- Modify `docs/features/agent/java-cli-terminal-mvp.md`: 更新当前真实实现，不再描述 `exec` 为可用任务入口。
