# 会话菜单与消息操作设计

## 背景

用户端聊天页当前已经具备会话重命名、删除、分享与重新生成的部分基础能力，但侧栏会话列表三点菜单仍只覆盖最小操作集，且与目标参考交互存在明显缺口。

本次改造目标是补齐用户侧会话菜单的核心操作能力，并把消息底部的分享、重新生成能力落到真实交互中。

## 目标

1. 会话列表三点菜单补齐以下能力：
   - 重命名
   - 置顶此对话
   - 分享此对话
   - 批量管理
   - 导出对话
   - 删除此对话
2. 不实现“移动到分组”。
3. 消息底部提供分享、重新生成按钮，并与会话级真实动作打通。
4. 全部交互兼容亮色/暗色主题，不使用浏览器原生弹窗。

## 约束

1. 当前后端已提供：
   - 会话分享接口
   - 会话重新生成接口
   - 会话重命名接口
   - 会话删除接口
2. 当前后端未发现现成能力：
   - 会话置顶
   - 会话导出
   - 批量管理
3. 因此新增能力默认以前端本地持久化与前端编排实现，不新增后端接口。
4. 侧栏会同时展示多个工作空间分组，菜单动作必须带上所属分组上下文，不能错误落到当前激活分组。

## 方案

### 会话置顶

在本地工作空间快照中新增 `pinnedConversationIds`，按分区持久化保存置顶会话顺序。

渲染与刷新规则：

1. 分区内会话列表先按 `pinnedConversationIds` 提升到顶部。
2. 其余会话保持原有顺序。
3. 会话被删除后同步从置顶列表移除。
4. 置顶操作不改后端，只影响当前用户本地视图。

### 侧栏菜单

继续沿用 `Portal + fixed` 浮层，扩展为两层结构：

1. 主菜单：重命名、置顶/取消置顶、分享、批量管理、导出、删除。
2. 导出子菜单：`Markdown`、`JSON`。

分享动作直接调用会话分享能力并复制链接。

### 批量管理

侧栏进入批量模式后：

1. 会话行左侧展示勾选框。
2. 顶部或底部展示批量工具条，支持：
   - 全选当前可见会话
   - 取消批量管理
   - 批量导出 Markdown
   - 批量导出 JSON
   - 批量删除
3. 批量删除使用自定义确认弹窗。

### 导出

导出基于会话回放数据生成文件：

1. `Markdown`：
   - 会话标题、会话 ID、导出时间
   - 消息正文
   - 可选步骤/来源/产物摘要
2. `JSON`：
   - 导出元数据
   - 原始消息、步骤、来源、产物、当前技能/MCP/专家

若目标会话本地快照缺少回放内容，则由前端临时请求回放接口拉取并写回快照后再导出。

### 消息底部操作

沿用当前助手消息操作栏：

1. 分享按钮复制当前会话分享链接。
2. 重新生成按钮仅允许最后一条助手消息触发。
