# Phase 3：Web 工作台闭环

更新时间：2026-05-12

## 一、概述

这一期把 Web 版任务体验真正做成闭环。

重点不是继续加页面，而是让任务工作台“活起来”，让用户能看到任务状态变化、日志流和结果摘要。

## 二、目标

- 建立 Web 工作台主视图
- 建立事件流
- 建立 mock executor
- 跑通任务状态闭环
- 把 Web 阶段收成一个可演示的 MVP

## 三、要做的事情

- 做 mock executor
- 做任务状态流转
- 做 SSE 或 WebSocket 事件流
- 做日志区
- 做步骤区
- 做结果摘要区
- 打通工作台实时刷新
- 完成任务创建 -> 运行 -> 完成 的演示链路
- 整理一份 Web MVP 验收清单
